# LLM Community Benchmarks: Leaderboard

Community-contributed results for local LLM inference. Every row is a single run submitted via pull request; this file is regenerated automatically on merge.

Tables are upsert-style: each contributor shows their latest run per tier (or per condition in the unranked table). Submitting the same setup again replaces that row, while older files stay under results/ and still count toward points.

Want to add your hardware? Read [CONTRIBUTING.md](CONTRIBUTING.md).

## Inference speed
